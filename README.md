# Portafolio Khan Academy - Gráficos Interactivos Web

Repositorio para la adaptación de proyectos gráficos de ProcessingJS (Khan Academy) a estándares web modernos utilizando **HTML5 Canvas**, **Tailwind CSS** y **p5.js**.

## Estructura del Proyecto

```text
├── index.html       # Estructura principal, navegación y diagrama DOM visual
├── style.css        # Estilos personalizados y configuración de scroll/canvas
└── script.js        # Lógica de la aplicación, selectores y sketches p5.js
```

## Instrucciones de Despliegue en GitHub Pages

1. Crea un repositorio público en tu cuenta de GitHub (por ejemplo, `khan-portfolio-web`).
2. Sube estos tres archivos (`index.html`, `style.css` y `script.js`) directamente a la rama principal (`main`).
3. Ve a **Settings** > **Pages** en tu repositorio.
4. En **Build and deployment**, selecciona la rama `main` y la carpeta `/ (root)` como fuente, luego haz clic en **Save**.
5. ¡Listo! En unos minutos GitHub te proporcionará la URL pública para ver tu portafolio en funcionamiento.

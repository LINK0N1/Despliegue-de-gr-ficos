# Portafolio Interactivo Khan Academy 🎨

Portafolio web interactivo y educativo que recopila y adapta 5 proyectos gráficos desarrollados originalmente en ProcessingJS (Khan Academy), migrados a estándares web modernos utilizando **HTML5 Canvas** y la librería **p5.js**.

---

## 🚀 Proyectos Incluidos

1. **Rana**: Ilustración colorida basada en el desafío de la rana loca, utilizando primitivas geométricas y arcos.
2. **Dientes de Conejo**: Simpático diseño de la cara de un conejo con orejas y dientes prominentes.
3. **¿Qué hay de cena?**: Composición de una mesa servida con plato principal y vajilla detallada.
4. **Día Nevado Soleado**: Paisaje invernal que combina un sol brillante y copos de nieve cayendo sobre montañas.
5. **Muñeco de Nieve**: Clásico muñeco de nieve con sombrero de copa, bufanda y accesorios detallados.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 Canvas**: Contenedor gráfico de mapa de bits de renderizado inmediato y contexto 2D.
* **p5.js (v1.6.0)**: Biblioteca de JavaScript para la creación simplificada de bocetos interactivos.
* **Tailwind CSS**: Framework CSS moderno para el diseño responsivo de la interfaz del portafolio.
* **FontAwesome**: Iconografía vectorial para la navegación y elementos visuales.

## 💻 Instrucciones de Ejecución Local

Para probar este proyecto en tu computadora de forma local:

1. Clona este repositorio o descarga el archivo `index.html`:
   ```bash
   git clone https://github.com/tu-usuario/khan-portfolio-web.git
   ```
2. Abre la carpeta del proyecto en tu editor de código preferido (por ejemplo, *Visual Studio Code*).
3. Abre el archivo `index.html` directamente en tu navegador web favorito (o utiliza una extensión como *Live Server*).

## 🌐 Guía de Despliegue en GitHub Pages

Para habilitar la visualización pública de tu sitio web de forma gratuita:

1. Sube los archivos fuente (`index.html` y `README.md`) a un repositorio público en GitHub.
2. Dirígete a la pestaña **Settings** (Configuración) de tu repositorio.
3. En el menú lateral izquierdo, selecciona la sección **Pages**.
4. En la sección **Build and deployment**, selecciona la rama principal (`main` o `master`) y haz clic en **Save**.
5. Copia la URL pública proporcionada por GitHub y utilízala para tu entrega.

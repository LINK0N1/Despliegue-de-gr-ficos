Arquitectura de Gráficos Web Estándar

Exhaustiva explicación de las tecnologías subyacentes utilizadas en la recreación de los dibujos y animaciones.

1. La Etiqueta HTML <canvas> y el Contexto 2D

La etiqueta <canvas> introducida en HTML5 es un contenedor gráfico programable mediante scripts (principalmente JavaScript). A diferencia de los elementos SVG (que se basan en un DOM vectorial), el canvas actúa como una matriz de pixeles de mapa de bits de renderizado inmediato.

  • El Contexto de Renderizado (`getContext('2d')`): Para dibujar sobre el canvas, es obligatorio solicitar un contexto 2D. Este objeto expone todas las APIs de dibujo de formas, rectángulos, trazados (paths), texto e imágenes.
  • Manipulación de Pixeles: Permite lectura y escritura directa de búferes de pixeles mediante getImageData() y putImageData(), ideal para filtros avanzados.
  • Sistema de Coordenadas: El origen (0,0) se sitúa por defecto en la esquina superior izquierda, con el eje X positivo hacia la derecha y el eje Y positivo hacia abajo.
// Ejemplo nativo de Canvas 2D
const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');
ctx.fillStyle = 'rgb(79, 70, 229)';
ctx.fillRect(10, 10, 150, 100);

2. Fundamentos de la Librería p5.js

p5.js es una biblioteca de JavaScript basada en el espíritu de Processing, diseñada para hacer la programación accesible a artistas, diseñadores y educadores, facilitando la creación de bocetos interactivos en el navegador.

  • Funciones Principales (`setup` y `draw`): setup() se ejecuta una sola vez al cargar la página para inicializar configuraciones y tamaños del lienzo. draw() se ejecuta en un bucle continuo (normalmente a 60 FPS), ideal para animaciones fluidas.
  • Abstracción del Contexto: Simplifica el dibujo complejo de canvas mediante funciones intuitivas como ellipse(), rect(), beginShape() y control completo de colores (fill(), stroke()).
  • Eventos Nativo-Integrados: Captura sencilla de interacción del usuario mediante variables como mouseX, mouseY o escuchadores como mousePressed().
// Estructura básica en p5.js
function setup() {
  createCanvas(400, 400);
}
function draw() {
  background(220);
  ellipse(mouseX, mouseY, 50, 50);
}

Guía de Despliegue y Entrega en GitHub Pages

Instrucciones claras para alojar y publicar este código fuente de forma gratuita y pública.

1

Crear Repositorio en GitHub

Crea un nuevo repositorio público en tu cuenta de GitHub (por ejemplo, nombrado khan-portfolio-web). Sube los archivos fuente (index.html) conteniendo la estructura completa del sitio.

2

Habilitar GitHub Pages

Dirígete a la pestaña Settings de tu repositorio, busca la sección Pages en el menú lateral, y selecciona la rama principal (main o master) como fuente de publicación (Deploy from a branch).

3

Obtener URL y Entrega

GitHub te proporcionará la URL pública de tu sitio web en funcionamiento (ej. https://tu-usuario.github.io/khan-portfolio-web/). Envía únicamente dicha URL a través del canal de entrega correspondiente.

La etiqueta <canvas> y el contexto 2D

<canvas> es un elemento HTML5 que reserva un rectángulo en la página para dibujar con JavaScript. Por sí solo está vacío: el HTML solo define su tamaño y los gráficos se generan con código.

<canvas id="lienzo" width="400" height="300"></canvas>

Contextos de renderizado

Para dibujar, se pide un contexto con getContext(). Los más comunes son:

  • "2d": dibujo bidimensional con formas, rutas, texto, imágenes y degradados. Es el que explicamos aquí.
  • "webgl" / "webgl2": gráficos 3D acelerados por la GPU.
  • "bitmaprenderer": muestra imágenes ya procesadas (ImageBitmap).
const lienzo = document.getElementById("lienzo");
const ctx = lienzo.getContext("2d");

ctx.fillStyle = "green";          // color de relleno
ctx.fillRect(20, 20, 100, 60);    // x, y, ancho, alto

ctx.beginPath();                  // una ruta (círculo)
ctx.arc(200, 100, 40, 0, Math.PI * 2);
ctx.strokeStyle = "black";
ctx.lineWidth = 3;
ctx.stroke();

Ideas clave del contexto 2D

  • Sistema de coordenadas: el origen (0, 0) está en la esquina superior izquierda; x crece hacia la derecha e y hacia abajo.
  • Estado de dibujo: propiedades como fillStyle, strokeStyle y lineWidth se aplican a todo lo que se dibuje después, hasta que se cambien.
  • Rutas: beginPath(), moveTo(), lineTo(), arc() y closePath() describen una forma; fill() o stroke() la pintan.
  • Transformaciones: translate(), rotate(), scale(), junto con save() y restore(), mueven el sistema de coordenadas.
  • Animación: se borra con clearRect() y se redibuja en cada cuadro con requestAnimationFrame().
  • Es raster: el canvas guarda píxeles, no objetos; una vez dibujada una forma, no se puede mover sin redibujar.

Fundamentos de p5.js

p5.js es una librería de JavaScript para programación creativa, inspirada en Processing (la base de los dibujos de Khan Academy). Crea un canvas y envuelve el contexto 2D en funciones sencillas como ellipse() o fill().

Estructura de un programa

function setup() {
  createCanvas(400, 400);   // se ejecuta una vez
}

function draw() {
  background(220);          // se ejecuta ~60 veces por segundo
  fill(0, 150, 0);
  ellipse(mouseX, mouseY, 50, 50);
}

Conceptos principales

  • setup() y draw(): setup prepara el lienzo; draw es el ciclo de animación.
  • Formas: rect, ellipse, triangle, arc, line, point, quad y bezier.
  • Color: fill, stroke, noFill, noStroke y background, en escala de grises, RGB (0–255) o con colorMode(HSB).
  • Variables del sistema: width, height, mouseX, mouseY, frameCount, mouseIsPressed.
  • Eventos: mousePressed(), mouseMoved(), keyPressed() responden a la persona usuaria.
  • Transformaciones: push(), pop(), translate(), rotate(), scale().
  • Utilidades: random(), map(), lerp(), sin(), cos(), dist(), constrain().

Modo instancia

En este sitio hay cinco dibujos en la misma página, así que cada uno usa el modo instancia: el programa se escribe dentro de una función que recibe el objeto p (p.ellipse(...)) y se monta en un contenedor con new p5(sketch, contenedor). Así no chocan entre sí.

Diferencias con Khan Academy

ProcessingJS y p5.js se parecen, pero p5.js usa createCanvas() en lugar de size(), mouseIsPressed sigue existiendo y background() se llama dentro de draw() para borrar el cuadro anterior.
